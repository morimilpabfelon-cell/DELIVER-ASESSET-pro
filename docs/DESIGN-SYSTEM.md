# Design System v0.1

Fuente de referencia: página `59:2 — Design System Production` del archivo Figma `DELIVER ASSETS — Editorial AI Concept`.

## Regla principal

**Editorial no equivale a UI operativa.**

La web corporativa puede utilizar Paper, Cream, composición expresiva y grandes titulares. Las aplicaciones operativas deben priorizar blanco, Ink, Blue, estados semánticos y superficies limpias.

## Tokens principales

- Brand Primary: `#1551D8`
- Brand Accent: `#FFC62F`
- Editorial Red: `#FF3328`
- Ink: `#111111`
- Paper: `#FAF3DF`
- Cream: `#F4E9C6`
- Surface: `#FFFFFF`

## Correcciones semánticas

- Danger operativo: `#E3261D`
- Success operativo: `#157A4B`
- Border interactivo: `#8C836F`

El rojo editorial no debe utilizarse automáticamente para acciones destructivas. Los componentes interactivos deben mantener foco visible, estados diferenciados y objetivos táctiles de al menos 44 px.

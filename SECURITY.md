# Seguridad

Este repositorio contiene un prototipo público. No debe recibir secretos, credenciales, datos personales, ubicaciones reales ni información de pagos.

Los hallazgos de seguridad no deben publicarse en issues abiertos. Deben comunicarse de forma privada al propietario del repositorio.

La presencia de componentes visuales de autenticación, pago o tracking no implica que esos controles estén implementados.

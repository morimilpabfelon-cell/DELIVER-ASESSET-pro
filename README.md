# DELIVER ASSETS Pro

Repositorio canónico para reconstruir DELIVER ASSETS como plataforma web-first y publicar una revisión visual mediante GitHub Pages.

## Superficies incluidas

- Plataforma corporativa.
- Customer.
- Business / DELIVER PRO.
- Rider, como previsualización web de la futura experiencia móvil.
- Control.

## Estado

**Prototipo técnico y visual.** No representa una plataforma productiva y no está autorizado para manejar usuarios, pagos, ubicación o operaciones reales.

## Desarrollo local

```bash
npm install --no-audit --no-fund
npm run dev
```

## Verificación

```bash
npm run build
```
